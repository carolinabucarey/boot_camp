Crea y publica tu proyecto web con IA

Convierte una idea clara en una primera solución web creada y publicada por ti.

4 horas en dos jornadas online en vivo · Nivel intermedio · 10 cupos · $74.990 CLP

Quiero participar

La experiencia

De una idea clara a una web que puedas mostrar

Trabajarás sobre una idea, proyecto o necesidad propia para convertirla en una primera solución web utilizando ChatGPT y Claude. Aprenderás a definir qué quieres construir, darle instrucciones claras a la inteligencia artificial, revisar lo que genera y publicar el resultado en internet.

No necesitas saber programar ni instalar Visual Studio Code.

Qué podrás crear

Una primera solución web funcional y acotada

  • Una página para presentar un proyecto, servicio o iniciativa.
  • Una página de aterrizaje.
  • Un portafolio profesional.
  • Una web informativa.
  • Una página de inscripción o contacto.
  • Un prototipo sencillo para mostrar y probar una idea.

El objetivo es que termines con una versión que puedas mostrar, utilizar y continuar mejorando.

Para quién es

Para avanzar más allá de los usos básicos de la IA

  • Quieres comprender cómo se crea, modifica y publica una web.
  • No sabes programar, pero quieres aprender a dirigir herramientas que generan código.
  • Buscas mayor autonomía para desarrollar y probar tus ideas.

Programa

Dos jornadas para definir, crear, mejorar y publicar

Día 1

De la idea a la primera versión

2 horas

Transformarás tu idea en una propuesta clara y comenzarás a construirla.

  • Definir qué quieres crear, para quién y qué necesidad debe resolver.
  • Acotar el proyecto para construir una primera versión.
  • Convertir la idea en instrucciones claras para la inteligencia artificial.
  • Definir contenidos, secciones y funciones principales.
  • Comprender cómo se relacionan ChatGPT, Claude, GitHub y Vercel.
  • Trabajar con un repositorio individual en GitHub.
  • Utilizar Claude Code desde el navegador.
  • Generar la primera versión y detectar mejoras.

Resultado: tendrás una primera versión de tu proyecto y una lista clara de mejoras.

Día 2

Mejora y publicación

2 horas

Mejorarás la primera versión y la publicarás en internet.

  • Probar la web y comprobar si responde al objetivo definido.
  • Solicitar cambios de contenido, diseño y funcionamiento.
  • Trabajar con versiones para no perder lo construido.
  • Revisar los cambios realizados por la inteligencia artificial.
  • Preparar una versión para publicación.
  • Conectar el repositorio de GitHub con Vercel.
  • Realizar el primer despliegue.
  • Comprender cómo conectar el dominio y volver a publicar.

Resultado: terminarás con una web publicada y un proceso para seguir modificándola.

Con qué terminarás

Una solución propia y un proceso que podrás repetir

    Metodología

    Aprendizaje práctico sobre tu propio proyecto

    Qué incluye

    Acompañamiento desde la definición hasta la publicación

    • Dos sesiones online en vivo.
    • Construcción guiada aplicada al proyecto de cada participante.
    • Repositorio individual preparado en GitHub.
    • Publicación inicial del proyecto en Vercel.
    • Dominio .cl por 12 meses, sujeto a disponibilidad.
    • Inscripción, configuración inicial y conexión del dominio realizada por MAILE.
    • Transferencia posterior del dominio a la participante.
    • Acceso a la comunidad MAILE para compartir avances, recursos y oportunidades.

    Alcance

    Una primera versión, no un producto completo a gran escala

    Por la duración del programa, trabajaremos en una solución web acotada. No incluye el desarrollo completo de tiendas en línea, sistemas de pago, plataformas con distintos tipos de usuarios, bases de datos complejas, aplicaciones con información confidencial ni productos listos para operar a gran escala.

    Si tu idea requiere estas funciones, podremos construir una primera versión visual o demostrativa y definir los próximos pasos.

    Dominio y publicación

    Tu proyecto quedará bajo tu control

    MAILE realizará la inscripción y configuración inicial del dominio `.cl`. Después de publicar el proyecto, deberás crear una cuenta en NIC Chile para que podamos transferirte la titularidad y la administración. La renovación posterior a los primeros 12 meses será tu responsabilidad.

    El proyecto se publicará inicialmente en tu cuenta de Vercel. Dependiendo del uso personal o comercial de la web, Vercel podría requerir posteriormente la contratación de un plan pagado.
